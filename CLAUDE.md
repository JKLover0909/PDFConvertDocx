# CLAUDE.md — PDF to DOCX Converter

## Overview
Python GUI application converting PDF documents to Microsoft Word (.docx) format with customizable settings.

## Key Files
- converter.py: GUI interface and conversion execution logic
- build.bat / build_simple.bat: PyInstaller configuration and build scripts
- requirements.txt: Python package dependencies

## Development
- Run application: python converter.py
- Build Windows EXE: Run build.bat
